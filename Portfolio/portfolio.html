INDUSTRIAL DESIGN WORK

Project Name

A brief, compelling description of the project and its scope (e.g., PHX IEM: A durable, modular in-ear monitor system designed for musicians and audio professionals, focusing on user-replaceable components and rugged aesthetics).

The Problem

The current market offerings for professional IEMs often lack user serviceability and durable, stage-ready construction. When a component fails, the entire unit must be sent in for costly repair or replacement. This project addresses the need for a truly modular, long-lasting product.

Action Items / Goals

  • Design a **modular enclosure** that simplifies component replacement.
  • Achieve an **IPX rating** suitable for professional use.
  • Develop a **quick-release locking mechanism** for the audio cable.
  • Maintain a **distinct, technical aesthetic** consistent with the brand.

Exploration & Solutions

Solution 1: Split Shell Concept

Initial idea of a two-part shell that screws together. Good for repair, but potentially weak at the seam.

Solution 2: Cartridge System

A self-contained audio unit that slides into a durable external sleeve. Excellent protection and easier replacement.

Solution 3: Magnetic Clasp

Testing a magnetic connection for cable/body interface. Fast, but less secure for vigorous stage use.

Solution 4: Final Locking Barrel

The final direction: a rotating barrel mechanism to ensure a secure, sealed connection.

Revisions & Feedback

Initial prototypes revealed that the internal component layout was too cramped, leading to difficult assembly. The main change was redesigning the internal chassis to be wider and integrating mounting points directly into the exterior shell to reduce part count.
